# Deliverables

Snapshots of what has been sent to Kevin Baker (Wessex Genomics Laboratory Service,
Salisbury), one folder per delivery, named by date. A folder is frozen once it is sent:
`results/` and `figures/` are always current, and a delivery folder shows exactly what was
handed over at the time.

## What goes in the repository, and what goes by email

The repository is public, so it only carries what we have the right to redistribute.

| In the repository | By email only |
|---|---|
| Figures and tables derived from CancerHotspots (ODbL) | Anything derived from **AACR Project GENIE** at the level of individual variants — the GENIE data-use agreement forbids redistribution |
| Summary figures from GENIE, as quoted in the report: cohort composition, numbers of changes per tier | Anything derived from **COSMIC** at the level of individual variants — COSMIC's licence permits use, not redistribution |
| The report, the written findings, the analysis code | |

Every delivery note says which files are in its folder and which were sent separately.
